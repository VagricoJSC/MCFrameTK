================================================================================

  FrameManager mini
  ver. 2.01

================================================================================

 1. 概要
--------------------------------------------------------------------------------
  iniファイルに設定した内容でFrameManagerの各種ビルダーを実行します。



 2. インストール
--------------------------------------------------------------------------------
  FrameManagerのインストールと同時に自動的にインストールされます。



 3. セットアップ
--------------------------------------------------------------------------------
 3-1. 基本設定
 3-1-1. 基本設定ファイルの用意
  以下のファイルを同じディレクトリにコピーし、ファイル名から"_sample"を削って
  "fmin.ini"という名前のiniファイルにします。

    <FrameManagerインストールディレクトリ>\bin\fmin\fmin_sample.ini

  作成したiniファイルを編集します。
  なお、行の先頭に "#" を付けるとその行はコメント行になり読み込まれません。

 3-1-2. 環境設定
  [INIT]セクションの以下のキーに設定します。

  fmhome
    <FrameManagerインストールディレクトリ>\bin を設定します。
    ex)
      fmhome=C:\FrameManager6\bin

  javahome
    使用するJavaVMのホームディレクトリを設定します。
    java(w).exeがあるディレクトリではないので注意してください。
    fmhome から相対パスで指定が可能です。
    ex)
      javahome=..\jre

  csvout
    FrameManagerが一時ファイルを作成するディレクトリを設定します。
    fmhome から相対パスで指定が可能です。
    ex)
      csvout=.\csv

 3-1-2. VMオプション
  JavaVMのオプションとして設定するものは[VMOPT]セクションに設定します。
  オプションに設定する文字列をそのまま記述してください。
  １オプションに付き１行にしてください。
    ex)
      -Xmx256m
      -DMCConfig#FM.OB.CONF_OUT="c:\work dir\conf"


 3-2. プロジェクト設定
 3-2-1. プロジェクト設定ファイルの用意
  fmin.ini と同じディレクトリに任意の名前でプロジェクト設定用のiniファイルを作
  成します。

 3-2-2. 自動生成設定の追加
  プロジェクト設定ファイルにプロジェクトで自動生成する設定を追加します。
  １実装仕様書につき１セクションを追加します。Excelファイル単位ではなく、実装仕
  様書の種類でセクションが分かれることに注意してください。
  セクションは以下の書式で記述してください。

    [ENTRY_<ID>]
    ex)
      [EXTRY_WUP0100]

  作成したセクションに以下のキーで情報を設定します。
  パスの場合、fmhome から相対パスで指定が可能です。

    title
      画面に表示するタイトルを設定します。
      ex)
        title=ログイン画面

    type
      実装仕様書の種類を以下のいずれかで設定します。
        画面実装仕様書        P
        ロジック実装仕様書    L
        共有メタ実装仕様書    M
        DBコンテナ実装仕様書  DBC
        帳票実装仕様書        R   ※このバージョンでは未対応
      ex)
        type=L

    xls
      入力になる実装仕様書のExcelファイルを設定します。
      typeが"DBC"の場合は、setting.xlsを設定してください。
      ex)
        xls=c:\spec\WUP0100.xls
      ※注意！！
        この設定を相対パスで指定するとJComでエラーが発生する恐れがあります。
        フルパスで指定するようにしてください。

    srcout
      生成したソースファイルの出力先を設定します。
      ex)
        srcout=..\src

 3-2-3. 基本設定の変更
  プロジェクト用に基本設定を変更する必要がある場合は、基本設定の記述と同じ要領で
  プロジェクト設定ファイルに記述することで変更することができます。
  セクションの記述を忘れないでください。

 3-2-4. プロジェクトの追加
  fmin.iniの[LIST]セクションに以下の書式でプロジェクト名と作成したプロジェクト設
  定ファイルを設定します。
  プロジェクト名は画面のプロジェクト選択リストに表示されるタイトルになります。
  プロジェクト設定ファイルにはパスをつけないでください。

    (プロジェクト名)=(プロジェクト設定ファイル)
    ex)
      Sample Project=SamplePJ.ini


 3-4. その他のセクション
  他のセクションは特に設定の必要はありません。説明だけしておきます。

  [CLASSPATH]
    FrameManagerを実行するためのクラスパスのエントリです。
    １行につき１エントリを記述します。パス接続文字 ";" は不要です。

  [PATH]
    FrameManagerを実行するために必要なDLLを読み込むためのパスのエントリです。
    １行につき１エントリを記述します。パス接続文字 ";" は不要です。

  [BUILDER]
    SPEC_CODEに対応するFrameManagerクラスのエントリです。



 4. 起動
--------------------------------------------------------------------------------
  ２通りの実行方法があります。


 4-1. Eclipseプラグインとして実行
  Eclipse内部のWebブラウザを表示し、以下のファイルを指定します。

    <FrameManagerインストールディレクトリ>\bin\fmin\fmin.html

  表示方法 例１:
   1) Eclipseのツールバーにあるブラウザ起動ボタン(地球儀のようなアイコン)を押す。
   2) 表示された画面のURLに上記ファイルをフルパスで入力する。
      ※スキーマ指定(file://)は不要。

  表示方法 例２:
   1) ナビゲータ等で、FrameManagerインストールディレクトリをプロジェクトとして登
      録するか既存のプロジェクトにFrameManagerインストールディレクトリをリンクす
      るなどして、上記ファイルをEclipse上で参照できるようにする。
   2) 上記ファイルを右クリックし、アプリケーションから開く->Webブラウザ を選択。


 4-2. スタンドアロンアプリケーションとして実行
  以下のファイルをダブルクリックして起動してください。

    <FrameManagerインストールディレクトリ>\bin\fmin.hta



 5. 操作方法
--------------------------------------------------------------------------------
 5-1. プロジェクトの選択
  コンボリストで対象のプロジェクトを選択してください。
  プロジェクト設定ファイルで設定した内容がテーブルに表示されます。


 5-2. 自動生成の実行
  各行にあるStartボタンを押すと設定内容で自動生成を実行します。

  なお、各行の先頭にあるチェックボックスは、このバージョンでは機能しません。


 5-3. 実行結果の確認
  正常終了すると、Statusの欄に終了日時が表示されます。
  警告終了すると、ポップアップメッセージとStatusの欄に"WARNING!"と表示されます。
  異常終了すると、ポップアップメッセージとStatusの欄に"ERROR!"と表示されます。


 5-4. 
  実行結果に関わらず、終了すると fmhome に fmin.log の名前で実行ログが出力されま
  す。




 6. その他
--------------------------------------------------------------------------------
  FrameManagerの実行のためにローカルPCのAciveXオブジェクトを使用します。そのため
  IEのセキュリティ設定によっては警告が表示されたり正常に動作しない場合が考えられ
  ます。
  その場合は専門家にお問い合わせください。

  各種ファイルは UTF-8 で記述されています。コードの変換はしないでください。
  iniファイルのみは、UTF-8ではなく、OSの文字コードかUnicode(UTF-16)で記述してく
  ださい。
